SpecViewer: a YAML file, shown as a web page

Twenty lines of C# that serve your hand-written openapi.yaml to Swagger UI. The server does not generate or change the spec. It only hands the file over.

What runs where

Line by line

  1. 1Start the web app. WebApplication.CreateBuilder and Build() create a bare server. It has no controllers and no endpoints yet.
  2. 2Find the spec. The code looks for ../openapi.yaml relative to the project folder. If it exists, that copy is used. If not, it uses the copy the build placed next to the DLL (see the .csproj).
  3. 3Serve it. MapGet("/openapi.yaml") reads the file on every request and returns it as application/yaml.
  4. 4Redirect the root. / sends you to /swagger so the base URL is useful.
  5. 5Mount Swagger UI. UseSwaggerUI serves the viewer at /swagger and points it at /openapi.yaml.

Why edits show up without a rebuild

The path is fixed at startup, so if you move or delete the live file while the app runs, it keeps pointing at the old location.

Why no code-first generation

The usual .NET setup generates the spec from controllers, so the code is the source of truth. This project reverses that. The YAML is the contract, and the C# only displays it. That fits a design-first lesson: you write the contract, look at it in Swagger UI, and only then build an API to match.

Because there are no real endpoints behind the spec, Swagger UI's "Try it out" buttons will fail against http://localhost:5000 unless something implements the API there.

The code

// 1. empty web server
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

// 2. prefer the live file, else the built copy
var live = Path.GetFullPath(Path.Combine(app.Environment.ContentRootPath, "..", "openapi.yaml"));
var specPath = File.Exists(live) ? live : Path.Combine(AppContext.BaseDirectory, "openapi.yaml");

// 3. hand the YAML to whoever asks
app.MapGet("/openapi.yaml", () => Results.Text(File.ReadAllText(specPath), "application/yaml"));
// 4. make / useful
app.MapGet("/", () => Results.Redirect("/swagger"));
// 5. the viewer, pointed at step 3
app.UseSwaggerUI(o => o.SwaggerEndpoint("/openapi.yaml", "Library API (hand-written)"));
app.Run();
